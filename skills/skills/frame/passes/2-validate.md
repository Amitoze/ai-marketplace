# Pass 2 — Validate

**Goal:** establish that the problem is real, for specific people, with
evidence — and specify the current state precisely enough that Pass 4
has something to measure the desired state against.

**Sits on:** Fitzpatrick, *The Mom Test* (past behaviour, never
opinions) · Torres, *Continuous Discovery Habits* (evidence from
continuous interviews) · Kepner-Tregoe IS/IS-NOT specification · Lewin,
force-field analysis (a current state is an equilibrium, not a void).

## Output (dossier §2) — the current-state spec

- **Bounds (IS / IS-NOT):** who exactly, in what situations,
  where/when, extent (frequency, severity) — and pointedly what this
  problem is NOT about.
- **Holding forces:** the forces that keep the current state in place.
  A current state persists because something maintains it; if nothing
  did, it would have self-corrected. Answering "why hasn't this fixed
  itself?" is this section's job.
- **Baseline observables:** what you would literally see or count today
  — incidents, behaviours, workarounds — with rough frequency.
- **Every claim evidence-tagged** per the conduct rules.
- **Open evidence requests:** the homework list — each parked question
  named with where the answer will come from (which interview cohort,
  which observation).

## Process

1. **Past-behaviour questioning only.** "What did you/they actually DO
   when this last happened?" — never "would people want…". Opinions
   about futures are not evidence; kindness inflates them.
2. **Convert speculation, don't argue with it.** Every "I think people
   would…" becomes an open evidence request, verbatim enough to hand to
   an interviewer.
3. **Fill the three current-state slots** (bounds, forces, baseline).
   The empty slot is the tool: a slot the user cannot fill is a finding,
   not a failure.
4. **Tag as you write.** An n=1 lived experience is `[measured]` for a
   portrait of that person and an assumption about everyone else —
   record both halves explicitly.

## Question bank

- When did this last happen? Walk me through what they did next.
- What did it cost them — time, money, a relationship, a decision?
- What have they already tried? What happened?
- Why hasn't this fixed itself? What holds the current state in place?
- When does it NOT happen — and what's different then?
- Who exactly is "people"? Name three real ones.

## Exit check

Either the load-bearing claims reach `[measured]`-or-better, or the gap
is carried honestly by the open-evidence-request list — the pass may
close "blocked on homework". Load-bearing claims still tagged
`[my-synthesis]` at close are flagged: Pass 5 will auto-promote them
into the assumption register.
