# Pass 4 — State

**Goal:** an unambiguous, customer-legible statement of the desired
state and the promise — precise enough that a stranger knows exactly
who gets what, solution-free enough to survive the solution being
swapped.

**Sits on:** Bryar & Carr, *Working Backwards* (Amazon PR/FAQ) ·
Ulwick's desired-outcome-statement grammar (direction + metric + object
+ context; measurable, solution-free, stable) · JTBD's three layers
(functional / emotional / social) · Simon, satisficing (the good-enough
threshold).

## Output (dossier §4) — the desired-state spec

- **Outcome statements** in Ulwick grammar: direction + metric + object
  + context ("minimize the number of X during Y"). Measurable in
  principle, naming no solution, stable if the solution changes.
- **Three layers:** functional (what works), emotional (how it feels),
  social (how relationships change). The emotional and social layers
  are the ones first drafts always omit — demand them.
- **Good-enough threshold:** the acceptance line. Desired ≠ perfect;
  an unstated threshold inflates scope forever.
- **The press-release paragraph** — drafted BY THE USER.
- **The hard FAQ:** 3–5 questions a skeptic would ask, with honest
  answers or honest "open" markers.

## Process

1. **The user drafts; the skill critiques — never the reverse.** The
   writing is where ambiguity surfaces; drafting it for them defeats
   the pass. Critique in rounds, one issue at a time.
2. **Hunt soft words.** Every "help", "support", "easier", "better"
   is challenged for an observable meaning: what would you SEE if this
   were achieved?
3. **Apply the grammar.** Recast the user's desired state as outcome
   statements; check each against Ulwick's four rules (measurable,
   controllable-in-principle, solution-free, stable over time).
4. **Demand the three layers**, then the threshold: "how accurate /
   how often / how many is enough to call this done?"
5. **Write the FAQ from the skeptic's chair.** Include the question the
   user least wants asked — it is usually the reframe Pass 1 rejected,
   returning for its rematch.

## Question bank

- If this went perfectly, what would a bystander observe that they
  can't observe today?
- Which of these words could two readers interpret differently?
- What does "good enough" look like — and what are you explicitly NOT
  promising?
- How does the person FEEL when the desired state holds? Who else's
  behaviour changes?
- A skeptic reads your paragraph and asks one hostile question — what
  is it?

## Exit check

The press-release test: a stranger reads the paragraph and can say who
gets what, without a follow-up question. Every outcome statement passes
the four Ulwick rules. The threshold is written down. The FAQ contains
at least one genuinely uncomfortable question.
