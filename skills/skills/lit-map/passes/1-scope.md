# Pass 1 — Scope

**Goal:** turn the dossier's kept frame into a ratified protocol —
review questions, candidate domains, inclusion rules, search strings —
written BEFORE any searching, so scope can't quietly bend to fit what
gets found.

**Sits on:** PRISMA-ScR (Tricco et al. 2018) protocol-first discipline ·
PEO/SPIDER question frameworks (qualitative-friendly; PICO only fits
narrow intervention questions) · rapid-review guidance on declaring
shortcuts up front.

## Output (protocol.md)

- The dossier's kept frame, quoted verbatim, with a pointer.
- 3–7 review questions, PEO-framed (Population, Exposure, Outcome) —
  or SPIDER where the question is about qualitative experience. Each
  question traces to a line of the kept frame or a §2 open evidence
  request; a question with no trace is scope creep.
- Candidate research domains (the disciplines likely to hold answers —
  e.g. health psychology, rehabilitation, HCI/accessibility). Marked
  guess vs known; Pass 2 corrects them.
- Inclusion/exclusion criteria: publication types, grey-literature
  types admitted, date bounds (justified, not reflexive), languages.
- Search strings per question (drafted for OpenAlex/PubMed syntax).
- Declared shortcuts section, verbatim from SKILL.md rule 4.

## Process

1. Read the dossier §1 (and §2 open requests). Do NOT read ahead into
   any literature yet.
2. Draft review questions WITH the user — propose, but the user is the
   authority on what the dossier needs answered. Challenge at least one:
   "which frame line does this question serve?"
3. Draft domains, criteria, strings. Anything tunable (date bounds,
   admitted grey types) is presented as a choice, not asserted.
4. Write protocol.md.
5. **GATE (user): ratify the protocol.** Present questions, domains,
   criteria, shortcuts; ask explicitly. No searching before the yes.
   Record ratification date in protocol.md.

## Exit check

protocol.md holds verbatim frame, traced questions, domains, criteria,
strings, declared shortcuts, and a dated user ratification. Zero
searches have been run.
